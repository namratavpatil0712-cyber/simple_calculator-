# Simple Interest Calculator

## Description

The Simple Interest Calculator is a basic program that calculates the simple interest and total amount based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest (SI) is calculated using the formula:

**SI = (P × R × T) / 100**

Where:

- **P** = Principal Amount
- **R** = Rate of Interest per year
- **T** = Time Period in years

The total amount is calculated as:

**Total Amount = Principal Amount + Simple Interest**

## Features

- Calculates simple interest quickly and accurately.
- Calculates the total amount.
- Easy to use and understand.
- Takes principal amount, rate of interest, and time as input.
- Provides clear output.

## Example

Suppose:

- Principal Amount = ₹10,000
- Rate of Interest = 5%
- Time = 2 years

Then:

**Simple Interest = (10000 × 5 × 2) / 100**

**Simple Interest = ₹1,000**

**Total Amount = ₹10,000 + ₹1,000 = ₹11,000**
